 # Portfolio Website  
واجهة شخصية بسيطة لعرض مهاراتي كمطور واجهات أمامية، مع أقسام توضح خبراتي، مشاريعي، وطرق التواصل معي.

## ✨ المميزات  
- تصميم بسيط وسهل التصفح  
- مبني باستخدام HTML وCSS  
- قابل للتطوير لإضافة JavaScript أو مكتبات مثل React لاحقًا  
- متوافق مع الأجهزة المحمولة  

## 📂 محتوى المشروع  
- **index.html** — الصفحة الرئيسية  
- **styles.css** — تنسيق الموقع  
- **assets/** — صور وأيقونات الموقع  

## 🚀 طريقة التشغيل  
افتح الملف `index.html` مباشرة في المتصفح، وسيعمل الموقع بدون أي إعدادات إضافية.
